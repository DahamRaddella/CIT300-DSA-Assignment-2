# Data Structure and Graph Performance Analyzer

## 📖 Project Description
This is a Java-based console application developed for the CIT300 Data Structures and Algorithms module (Graded Practical Assignment 2). The system demonstrates the practical application of core data structures, algorithms, searching techniques, graph traversals, and algorithmic complexity performance comparison.

## 🚀 Technologies Used
* **Programming Language:** Java (JDK)
* **Architecture:** Object-Oriented Programming (OOP)
* **Version Control:** Git & GitHub (Branches, Commits, Pull Requests)
* **Interface:** Command-Line Interface (Console)

## ✨ Main System Features
1. **Array Operations:** Insert, Delete, Display.
2. **Stack Operations:** Push, Pop, Peek, Display (with Overflow/Underflow handling).
3. **Queue Operations:** Enqueue, Dequeue, Peek Front, Display (with Circular constraints).
4. **Linked List Operations:** Insert, Delete, Search, Display.
5. **Searching Algorithms:** Linear Search and Binary Search functionalities.
6. **Graph Operations:** Add Vertices, Add Edges, Display Adjacency List.
7. **Graph Traversals:** BFS and DFS Traversal representations.
8. **Performance Comparison:** Execution time and algorithmic step comparison between Linear vs. Binary Search and BFS vs. DFS Traversals.
